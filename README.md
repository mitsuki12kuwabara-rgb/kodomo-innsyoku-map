# こども飲食マップ

子どもに寛容な飲食店を地図でさがせる、子育て世代向けのマップです。地図から、または一覧・条件で絞り込んでお店の詳細（写真・特徴・設備・現在地からのルート）を確認できます。

## 公開URL（GitHub Pages）

デプロイ後に有効化されます：
`https://mitsuki12kuwabara-rgb.github.io/kodomo-inshoku-map/`

## 特徴

- 地図（国土地理院タイル）にお店をマッピング。ピン／一覧のどちらからでも詳細を表示
- 条件で絞り込み：区市町村 → 地域、設備（ベビーカー可・おむつ替え・授乳室・ベビーチェア・キッズメニュー・子供用食器・個室/半個室・座敷/ソファー）、いいね数トップ20位
- お店の詳細から Google マップで現在地からのルートを表示
- スマホは Google マップ風のボトムシート（下から引き上げて一覧を拡大）
- 閲覧専用（画面からの編集は不可。内容は `data.js` を編集して更新）

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面本体（HTML/CSS/JS 一体・外部フレームワーク不要） |
| `data.js` | お店データ（このファイルを編集して追加・更新） |
| `images/` | お店の写真 |

サーバー不要の静的サイトです。ローカルで見るときは `index.html` をブラウザで開くだけ（地図タイルの読み込みにはインターネット接続が必要）。

## 出典・クレジット

- 地図タイル：地理院タイル（国土地理院）
- 地図ライブラリ：Leaflet（BSD-2-Clause）
- ルート案内：Google マップ（経路リンク）
- 住所→座標：国土地理院 住所検索（作成時のみ利用・座標は静的保存）
- 店舗情報・写真：Instagram『せたがやおやこレストラン』(@oyako_de_restaurant) の投稿を基に整理

掲載情報は投稿時点の内容です。設備・営業状況は変更される場合があるため、来店前に各店舗の最新情報をご確認ください。
